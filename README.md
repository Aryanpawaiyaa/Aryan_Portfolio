# Creative Portfolio - Aryan Narwariya

A premium, interactive personal portfolio website showcasing work, technical certifications, visual creations, and systems engineering essays.

Built with **React**, **TypeScript**, **Vite**, **Tailwind CSS**, and **Framer Motion**.

## Features

- **Interactive Environment**: Dynamic 3D lens-warped grid lines and floating particle field that interact with the cursor.
- **Optimized Asset Pipeline**: Statically resolved WebP images, automatic vector badges, and responsive placeholders.
- **Timeline Display**: Detailed CV history showing professional experience and academic background.
- **Responsive Views**: Seamless, smooth-scrolling tab system designed for all screen layouts.

## Getting Started

### Prerequisites

Ensure you have **Node.js** installed on your system.

### Installation

1. Clone this repository to your local machine.
2. Install the project dependencies:
   ```bash
   npm install
   ```

### Development

Start the local development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

### Build & Deploy

Compile the production-ready static assets:
```bash
npm run build
```
The output will be built inside the `/dist` directory, ready to be deployed to any static host (Cloudflare Pages, Vercel, Netlify, or GitHub Pages).
